# 🏋️‍♂️ Workout Tracker – Backend (Spring Boot)

This is the backend of the Workout Tracker application built with **Spring Boot**. It provides a RESTful API for managing workouts.

---

## 🧰 Tech Stack

- Java 17+
- Spring Boot
- Maven
- H2 Database (in-memory)

---

## 🚀 Getting Started

### ✅ Prerequisites

- Java 17 or later installed
- Maven installed (or use the included wrapper `./mvnw`)

---

### ⚙️ Run the Backend

```bash
# Navigate to the backend directory
./mvnw spring-boot:run
